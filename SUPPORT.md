# Support

- Read the [README](./README.md) for installation, setup, and command usage.
- Search [existing issues](https://github.com/M003aad/MetaData.Js/issues) for known problems.
- If you cannot find an answer, open an issue with your Node.js version, command, and a clear description of the problem.
- For security vulnerabilities, use the private channels in [SECURITY.md](./SECURITY.md), not a public issue.
