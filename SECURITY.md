# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use [GitHub Private Vulnerability Reporting](https://github.com/M003aad/MetaData.Js/security/advisories/new) or email [188705139+M003aad@users.noreply.github.com](mailto:188705139+M003aad@users.noreply.github.com).

Include the affected version, a description of the issue, steps to reproduce it, and any relevant impact. Avoid attaching images containing personal or sensitive information.

## Response and fixes

The maintainer aims to acknowledge reports within seven calendar days and provide an initial assessment within fourteen calendar days. Confirmed vulnerabilities will be prioritized according to severity and impact; fixes will be released as soon as reasonably practical. These targets are best-effort and may vary with severity and maintainer availability.
